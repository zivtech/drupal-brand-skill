# Drupal Brand Typography

This folder contains the **official Drupal brand typefaces**.

## Font Files

- `ZT Gatha - Bold and SemiBold.zip` - Primary headline typeface
- `Noto_Sans.zip` - Secondary body typeface

## Typography System

### Primary Typeface: ZT Gatha

**Usage**: Headlines, Subheads, H1 Tags

| Weight | Use Case |
|--------|----------|
| Bold | Primary headlines, H1 |
| SemiBold | Subheads, emphasis |

**Note**: When using a language not supported by ZT Gatha, substitute with Noto Sans Bold.

### Secondary Typeface: Noto Sans

**Usage**: H2 tags, Eyebrows, Body copy

| Weight | Use Case |
|--------|----------|
| Bold | H2 headlines, emphasis |
| Bold Italic | Emphasized quotes |
| Medium | Subheadings |
| Medium Italic | Emphasized body text |
| Regular | Body copy |
| Italic | Citations, emphasis |

**Note**: Noto Sans is a "World" font with comprehensive language support.

## Typography Hierarchy

| Level | Size | Weight | Typeface |
|-------|------|--------|----------|
| H1 | 48-60px | Bold | ZT Gatha |
| H2 | 36-42px | Semibold | ZT Gatha or Noto Sans Bold |
| H3 | 24-30px | Semibold | Noto Sans |
| Body | 16-18px | Regular | Noto Sans |
| Small | 12-14px | Regular | Noto Sans |

## Best Practices

- **Line height**: 1.5 for body text, 1.2 for headings
- **Paragraph spacing**: 1em
- **Optimal line length**: 60-80 characters

## Sub-branding Typography

- Use **Noto Sans Bold** for all sub-branding
- Sub-brand colors: Drupal Blue or Drupal Navy only
- White logo requires white sub-brand text

## Installation

Extract the ZIP files and install fonts on your system:

- **macOS**: Double-click font file → Install Font
- **Windows**: Right-click font file → Install
- **Linux**: Copy to `~/.fonts/` or `/usr/share/fonts/`
