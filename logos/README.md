# Drupal CMS Product Logos

This folder contains **Drupal CMS product-specific logos** for use in CMS marketing, documentation, and product materials.

## Folder Structure

```
logos/
├── svg/                    # Vector format (scalable)
└── png/
    ├── large/              # High resolution
    ├── medium/             # Medium resolution
    └── small/              # Low resolution / thumbnails
```

## Logo Variations

| Variant | Description | Use Case |
|---------|-------------|----------|
| Horizontal + Wordmark | Logo with "Drupal CMS" text side-by-side | Headers, wide spaces |
| Horizontal + No Wordmark | Logo icon only, horizontal layout | Small spaces, icons |
| Vertical + Wordmark | Logo with "Drupal CMS" text stacked | Tall spaces, banners |
| Vertical + No Wordmark | Logo icon only, vertical layout | Square spaces, favicons |

## Color Variants

- **Blue**: Use on light/white backgrounds
- **White**: Use on dark backgrounds, gradients, or photos

## When to Use These Logos

- Drupal CMS product pages and documentation
- CMS-specific marketing materials
- Commercial hosting and service provider materials
- Product comparisons and feature highlights

## When NOT to Use These Logos

For general Drupal community materials, events, or non-CMS-specific content, use the **primary Drupal logos** located in `/graphics/`.

## File Format Guide

| Format | Best For |
|--------|----------|
| SVG | Web, print, any size needed |
| PNG Large | Print materials, large displays |
| PNG Medium | Web graphics, presentations |
| PNG Small | Thumbnails, small UI elements |
