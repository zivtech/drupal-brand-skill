# Drupal Brand Gradients

This folder contains **official gradient treatments** for Drupal brand designs.

## Available Gradients

| File | Colors |
|------|--------|
| Drupal Gradients-Dark Blue Light Blue.svg | Deep blue to sky blue |
| Drupal Gradients-Navy Blue.svg | Navy variations |
| Drupal Gradients-Purple Blue.svg | Purple to blue |
| Drupal Gradients-Red Purple.svg | Red to purple |
| Drupal Gradients-Red Yellow.svg | Red to yellow |
| Drupal Gradients-Yellow LIght Blue.svg | Yellow to light blue |

## Usage Guidelines

### Logo Usage on Gradients

- Only **Drupal Navy**, **White**, or **Black** logos can be used on gradients
- Never use Drupal Blue logo on gradients

### Text on Gradients

**50/50 gradient split**: Text color must meet W3C contrast compliance with both gradient colors.

**Uneven gradient split**: Text color must be compliant with the color directly underneath.

### Applications

- Hero section backgrounds
- Banner backgrounds
- Accent elements
- Image overlays (at 30-50% opacity)

## File Format

All gradients are provided as **SVG** files for scalability and easy color extraction.
