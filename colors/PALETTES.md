## W3C Contrast Compliance

Maintain WCAG AA contrast ratios (minimum 4.5:1) for all text.

**Grey Usage Note**: Grey is allowed in many color applications. Please use a W3C compliant value when choosing a Grey.

**Gradient Usage**: When gradients are 50/50 value, text must be compliant with both colors. When gradients have an uneven split, text must be compliant with the color directly underneath.
