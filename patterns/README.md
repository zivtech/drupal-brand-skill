## About Dynamic Patterns

These patterns are inspired by classic computing screen savers and GUI elements. They add depth and visual interest to designs while maintaining brand consistency.

## Usage Guidelines

### Do's

- Use as subtle backgrounds at 10-20% opacity
- Apply to section dividers and breaks
- Pair with solid brand colors
- Use to add texture to large empty spaces

### Don'ts

- Do not use unapproved patterns (only these 6 are official)
- Do not let patterns overpower primary content
- Do not use at full opacity over important content
- Do not modify the pattern shapes or colors

## Recommended Opacity by Use Case

| Use Case | Opacity |
|----------|---------|
| Hero section background | 10-15% |
| Section divider | 15-20% |
| Slide background | 10-15% |
| Print background texture | 5-10% |

## File Format

All patterns are provided as **SVG** files for maximum scalability.
