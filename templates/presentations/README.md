## What's Included

- Title slides with proper logo placement
- Content layouts using brand typography
- Color schemes matching official Drupal palette
- GUI Block design elements
- Gradient and pattern backgrounds

## Usage Guidelines

- Use ZT Gatha Bold for headlines
- Use Noto Sans for body text
- Stick to approved color combinations (see `/colors/PALETTES.md`)
- Maintain logo clear space requirements
- Ensure text contrast meets WCAG AA standards (4.5:1 minimum)
