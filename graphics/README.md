# Primary Drupal Logos

This folder contains the **primary Drupal logos** (Drop icon and wordmark variations) for general Drupal use.

## Folder Structure

### `/svg/` folder
Primary Drupal logos in vector format for print and scalable web use

### `/png/` folder
Primary Drupal logos in raster format (large, medium, small sizes) for digital applications

### Root folder PNG files
Additional logo variants for quick use:
- drupal-logo-wordmark-blue.png - Full logo with wordmark
- drupal-drop-icon-blue.png - Drop icon only (blue)
- drupal-drop-icon-white.png - Drop icon only (white, for dark backgrounds)
- drupal-logo-badge-blue.png - Square badge format
- drupal-logo-badge-blue-alt.png - Square badge variant

**Note**: For Drupal CMS product-specific logos, see `/logos/`.

## Usage Guidelines

### When to Use Each Logo

**Primary Drupal Logo** (from `/svg/`)
- General Drupal community materials
- Events and meetups
- Contribution and advocacy
- General marketing

**Drupal CMS Logos** (from `/png/`)
- Specifically for Drupal CMS product
- Product documentation
- CMS-specific marketing
- Commercial hosting materials

### Clear Space
Maintain clear space equal to 1/4 the height of the logo on all sides

### Minimum Sizes
- Digital: 120px wide minimum
- Print: 1 inch wide minimum

### Acceptable Backgrounds
- White or light backgrounds (use blue logo)
- Dark backgrounds (use white logo)
- Solid brand colors with sufficient contrast
