# Slide Backgrounds

This folder contains **background images** for presentations and marketing materials.

| File | Description |
|------|-------------|

| orange-gradient-drop.png | Orange gradient with drop shape |

## Usage Guidelines

- Use as slide backgrounds in presentations
- Ensure text has sufficient contrast against backgrounds
- Pair with appropriate logo colors (see CLAUDE.md for guidance)
- On gradient backgrounds, use Navy, White, or Black logos only

## Recommended Text Colors

| Background | Text Color |
|------------|------------|
| Blue backgrounds | White |
| Orange/Yellow backgrounds | Navy or Black |
| Black/White gradient | Depends on position |
