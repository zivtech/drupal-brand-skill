## GUI Blocks

GUI Blocks are modular graphic elements inspired by classic computing interfaces. They add depth and brand recognition to designs.

### GUI Block Rules

- Maximum 3 colors per block (including white)
- 0-3 control dots depending on available space
- Do not fill control dots
- No gradients inside GUI Blocks
- Corner radii must match on corresponding corners

### Creating Custom GUI Blocks

1. Create rectangle at desired size
2. Round corners
3. Duplicate and shift diagonally at 45° (not closer/further than 3 line widths)
4. Round inner and outer corners to match
5. Add control dots and shadow lines at 45°
